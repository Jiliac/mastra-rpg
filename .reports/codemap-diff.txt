Architecture changes
================================================================================

  • End-to-end loop now live: /play/<slug> → POST /api/turn (SSE) → reducer
    → audio (/api/turn/audio) + images (/api/turn/image) rendered in-browser.
  • src/lib/media/tts.ts has graduated from "module present, not wired" to a
    first-class workflow step (writes <vault>/audio/narrator-<turnId>.ogg via
    ttsWithRetry; served back via /api/turn/audio).
  • Concurrency invariant #3 is now implemented at the route level: client
    disconnect flips clientGone and stops draining, but the workflow continues
    so persists complete on the FS even after the client closes the tab.
  • Mutex contention (acquireMutex returns false) surfaces as a recoverable
    error {message:'still working'} — UI handles via MutexBanner.
