mastra-rpg — Architecture map

Next.js 16 + Mastra. Local-only RPG runtime ported from OpenClaw. Waves 1–6 are merged on main. End-to-end loop is live at /play/<slug>. Click a node to inspect.

State of play. A player POSTs a turn to /api/turn; the route SSE-bridges PhaseEvents from runTurn (5 steps, mutex held throughout) back to a React reducer in /play/[slug]. Audio + image assets are served from /api/turn/{audio,image}. The starter /api/chat route is still present but stale (references the deleted weather-agent) and is slated for deletion.
